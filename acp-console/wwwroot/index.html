🚀 Deploy a new policy version

Paste a policy in the YAML DSL. acp-server validates and signs it, then the proxy hot-reloads it only after verifying that signature. A policy that does not compile is rejected and nothing is written. Scope a rule to an app or agent with app: / agent: inside its when.

➕ Register an AI endpoint

Register an endpoint for an AI agent or provider (for example claude.ai, chatgpt.com, api.x.ai, api.openai.com, or an MCP server URL). acp-server classifies the provider and records a signed disposition. govern routes it through ACP and counts it as governed; block quarantines it; accept-risk is a time-boxed exception.

⚠ Engage or clear the kill-switch

Engaging writes a signed, scoped grant acp-server hands to the proxy. Lockdown denies matching calls and STAYS locked until cleared; scope it (resource:database, agent:triage) to contain one resource or agent without downing the fleet.

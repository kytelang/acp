➕ Register a team / application
➕ Register an agent

An agent belongs to a team (app). Registering returns a one-time token; store it now, it is not shown again.

➕ Register an AI endpoint

An AI agent or provider (for example claude.ai, chatgpt.com, api.x.ai, or an MCP server URL). The provider is classified automatically. govern routes it through ACP; block quarantines it; accept-risk is a time-boxed exception.

➕ Create a governance record

Ed25519-signed by the control plane and stored in the control-plane database. Details is free-form JSON or text specific to the kind.

⚠ Engage or clear the kill-switch

Engaging writes a signed, scoped grant the proxy watches. Lockdown denies matching calls and STAYS locked until cleared; scope it (resource:database, agent:triage) to contain one resource or agent.
